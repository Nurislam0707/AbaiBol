### **Elevate the Campus Experience through Transparent & Anonymous Feedback.**

**Nuris Feedback** is a state-of-the-art Flutter mobile application designed to empower students by providing a safe, anonymous, and interactive platform to share their campus experiences. From rating instructors to evaluating building facilities, Nuris bridges the gap between students and university administration.

---

## ✨ Key Features

### 👤 **True Anonymity**
Share your honest thoughts without fear. All reviews are posted anonymously, ensuring a safe space for constructive criticism and praise.

### 🏛️ **Multi-Category Feedback**
Nuris covers all aspects of campus life:
- **Teachers**: Rate instructors and departments.
- **Subjects**: Share opinions on course difficulty and quality.
- **Buildings**: Evaluate campus facilities and services.
- **Student Life**: Give feedback on the quality of university living.
- **Clubs**: Review interest-based clubs and organizations.

### 📈 **Real-time Leaderboards**
Discover what's trending and who remains at the top.
- **Top Rated**: Recognition for the best instructors and facilities.
- **Trending**: Real-time momentum indicators showing which sections are getting the most attention right now.

### 🔍 **QR Integration**
Quickly jump into feedback by scanning QR codes located at building entrances or classroom doors.

### 💎 **Premium Glassmorphism UI**
Built with a "Glassmorphism" design system, Nuris offers a premium, modern, and fluid user interface that feels alive with micro-animations and smooth transitions.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (v3.11+)
- Android Studio / VS Code
- A Supabase Project

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Nurislam0707/abaibol.git
   cd abaibol
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Configure Environment**
   Update your Supabase credentials in the initialization logic.

4. **Run the application**
   ```bash
   flutter run
   ```
